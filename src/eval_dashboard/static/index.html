How to use this

Controls

  • Move your hand in front of the camera — the cursor follows it.
  • Open palm = no click. Closed fist = click.
  • ESC is the kill-switch: it instantly stops all simulated input, from anywhere, even if the browser isn't focused.

Running a trial

  1. On the Start tab, optionally pick a different Model — each is a checkpoint under models/; the picker shows its offline test accuracy so you can tell them apart.
  2. If the model is a fist-vs-rest checkpoint, a Click strategy picker appears — pick a click-FSM tuning preset (how eagerly a fist commits a click). It locks once the tracker starts.
  3. Click 1 · Start hand tracker — this opens the camera and loads the model (a few seconds). The status chip (top-left) turns green once your hand is seen.
  4. Click 2 · Start course and clear the three obstacles: precision clicking, rapid clicks, and a line trace.
  5. Hit Finish & Rate — this stops the tracker (kill-switch) so you can answer the 5-question survey with the normal mouse.
  6. Submitting writes the run to eval_results/ (a .docx/.txt report plus a .json) and it shows up on the Overview tab.

Reading the Overview tab

  • The Model metrics table is offline numbers (test accuracy from each checkpoint's own writeup) — useful for comparing models even before a live trial exists for one of them.
  • The trial table/charts below are live runs recorded through this page. Filter, sort, or chart by model, strategy, or any obstacle metric to compare runs head-to-head.
  • Offline accuracy and live feel can disagree — a saturated benchmark (e.g. 100% test accuracy) doesn't guarantee the better live trial; that's what running the course is for.

Full write-ups: DOCS/models/<name>/README.md per checkpoint, DOCS/build/strategies/3-cursor-and-click/ for the click-FSM presets.
