## Week 2 — Data Validation & Understanding (2026-07-12)

- Pointing Claude at the **assignment rubric file in-repo** (`DOCS/assignments/data_understanding.md`) plus my existing pipeline code let it map deliverables to what already existed instead of rebuilding.
- Insisting figures/numbers be **generated by executing the real pipeline** (not hand-written) kept the report honest and reproducible.
